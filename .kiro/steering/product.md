# Product steering — Graveyard Tasks

Graveyard Tasks is a Halloween task manager. English only. No accounts, no servers, no tracking.

- **One job, done well.** Add a task, see it as a tombstone, finish it and watch it rise as a ghost. Nothing else competes for attention.
- **State must be visible at a glance.** Active = tombstone. Overdue = skeleton with a red OVERDUE tag. Completed = ghost, faded, in Rest in Peace. Never rely on colour alone — always pair it with an icon and a text tag.
- **Forgiving by default.** Delete and clear-completed always confirm first. Import validates and rejects bad files without touching current tasks.
- **Readable over spooky.** Dark theme and Halloween decorations must never hurt contrast or button clarity. If a decoration makes text harder to read, the decoration goes.
- **Offline first.** The app must work by opening index.html with no network. No external fonts, images, or scripts.
